# 《机械翼龙：投放突袭》美术规范

## 视觉定位

这是一款手机竖屏固定射击游戏。画面像摆在浅色展柜中的积木战场：干净、温暖、可读性优先。坦克是底部攻击方；翼龙战车是上方来袭编队。模型保持真实积木的黄、黑、灰结构，不做写实战争或重金属机甲。

关键词：**积木实体、浅色档案、竖屏街机、清晰预警、轻量动效。**

## 色彩与材质

| 角色 | 色彩 | 使用规则 |
| --- | --- | --- |
| 页面与战场底色 | 米白 `#F7F7F1`、雾绿 `#DFE9E4` | 大面积低对比，衬托模型。 |
| 主模型 | 明黄、石墨黑、机械灰 | 忠实保留积木比例与塑料反光。 |
| 玩家弹药与得分 | 能源金 `#EFB63B` | 只用于积极反馈和弹丸。 |
| 受击与危险 | 珊瑚红 `#D66F5D` | 只用于装甲、受击和短时危险反馈。 |
| 失效状态 | 灰绿 `#AAB3AC` | 装甲耗尽格、已结束目标。 |

材质使用柔和塑料高光、圆角和积木卡扣细节。禁止重纹理、脏污、霓虹和高频背景图案。

## 镜头与模型

- 游戏镜头为固定俯视，模型车顶朝向镜头，车头默认指向屏幕上方。
- 玩家坦克位于底部操作区上方；不得被 HUD、提示或按钮遮住。
- 合体翼龙战车在上方横向巡航，始终保持俯视轮廓。
- 战车被投放后切换为侧面轮廓并向下坠落；翼龙则掉头，以俯视轮廓俯冲。
- 所有模型缩放以手机竖屏为准：敌方编队、弹丸、坦克和触控区之间必须有清晰空隙。
- 横移和俯冲目标不得越出相机可视边界。

## 战场与 UI

- 战场背景使用纯净雾绿；不使用横线、网格、漂浮装饰或会干扰轨迹判断的纹理。
- HUD 保持三段：积分、波次/剩余编队、四格装甲。
- 装甲固定显示四条短条：存活为珊瑚红，损失后原位变灰，不能移除或重新排版。
- 触控按钮置于底部：白色方向键，黄色发射键；按钮需有按下缩放、颜色变深和轻微内阴影。
- 所有可长按元素禁用文本选择与系统长按菜单。
- 关卡内不显示常驻文字提示；结果和规则放在开始页、暂停页或 HUD 中。

## 动效与反馈

- 合体巡航：轻微横移和小幅摆动，不能造成镜头或屏幕晃动。
- 投放：侧面战车平稳下落，翼龙在约 0.5 秒内掉头再俯冲。
- 击中：短暂黄色积木粒子；受击：一次珊瑚色粒子。不要用火焰、爆炸烟雾或持续闪烁。
- 点按反馈时长控制在 `120ms` 左右；状态动效控制在 `180–700ms`。
- 系统减少动态效果时，保留颜色与位置反馈，取消非必要粒子。

## 验收清单

1. 手机竖屏第一眼能分清底部坦克、上方合体编队和下落战车。
2. 模型、弹丸、触控键和 HUD 不互相遮挡。
3. 危险只使用短时珊瑚色，不用红色铺满背景。
4. 模型均在镜头边界内活动。
5. 新增美术元素不能降低弹道和落点的可读性。
