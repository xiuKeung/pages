# 《机械翼龙：投放突袭》关卡设计规则

本文件是关卡内容的唯一设计基线。后续新增、调整关卡时，先遵循本文件，再修改 `levels.js`；不要把关卡节奏、道具概率或难度判断写进渲染代码。

## 设计目标

游戏是竖屏自动射击：玩家操控底部坦克横移，击落顶部的合体机械翼龙战车，躲避敌方炮火、投放战车与翼龙俯冲。每一关应让玩家读懂一个新的压力、在下一波练习它，再在第三波做一次检验。

关卡难度来自可读的选择，不来自无解的同时攻击。任意时刻都应保留一条可横移到达的安全路线；不要在同一横向区域同时叠加投放战车、俯冲翼龙和敌方炮火。

## 20 关结构

|章节|关卡|训练主题|预期剩余装甲|
|---|---:|---|---:|
|识别|01–05|认识合体、投放、炮火、编队与落点|3–4 格|
|预判|06–10|提前判断两种压力的先后顺序|2–3 格|
|选择|11–15|在有限强化中选择更适合当前波次的解法|约 2 格|
|掌握|16–20|连续移动、击落与接强化的综合判断|1–2 格|

每关固定三波：

1. **识别波**：只突出本关主压力，首个危险动作要留出观察时间。
2. **练习波**：保留已学压力，再加入主压力；可投放一个偏进攻的强化。
3. **检验波**：提高节奏或耐久，只给一次关键的防守或节奏强化。

## 数值与安全边界

- 一关只增加一个主压力：敌机数量、耐久、漂移、投放节奏、炮火节奏、俯冲速度或强化缺失，不能一次同时大幅提高多个值。
- `count` 为 3–10；早期用少敌机讲清规则，后期用更多敌机形成持续压迫。
- 合体敌机 `health` 为 2 或 3。3 点耐久只从第 13 关开始使用。
- `firstDeployAfter` 与 `firstProjectileAfter` 是首次危险动作的秒数；新机制第一次至少预留约 4 秒。
- `deployEvery` 不低于 1.85 秒，`projectileEvery` 不低于 1.7 秒。
- `diveSpeed` 保持在 6.2–9.6，后期应优先提高节奏或编队，而不是无限提高速度。
- `deployPattern: 'single'` 用于教学与低压波；`'alternate'` 交替选择横向位置，避免持续封死同一路径。
- `driftPattern` 可用 `still`、`sway`、`sweep`、`pulse`。新样式先在识别波出现。

## 强化投放规则

强化是减压窗口，不是通关前提。所有关卡都必须可以在不吃到强化的情况下完成；强化只奖励位置判断、加快清场或降低风险。

|强化|用途|持续时间|投放原则|
|---|---|---:|---|
|双炮|两条平行子弹；与散射互斥|9 秒|适合单体耐久或窄编队|
|散射|三方向子弹；与双炮互斥|8 秒|适合宽编队|
|速射|射击间隔变为原来的 50%|8 秒|适合连续清场|
|护盾|抵消一次攻击并给出明显受击反馈|7 秒|用于高风险检验波|
|减速时间|敌方移动、投放、俯冲与炮火按 0.55 倍速推进|7 秒|用于需要重新找路线的波次|

投放约束：

- 不采用“每击败 N 个敌人必掉落”的全局循环。每个波次在 `powerDrops` 中显式编排。
- 不要求每关都有道具；20 关中应保留至少 4 关完全无投放。
- 同一波不要同时投放护盾与减速时间；低压波不要叠加进攻强化与速射。
- 每波最多 2 个强化，常规为 0–1 个；一个掉落应在 `afterDefeat` 对应敌机被击败时出现。
- `landing: 'safe'` 在坦克附近的安全区域投放，`'gap'` 投在当前队形可接近的缺口；不要用高风险落点强迫玩家接道具。

当前 20 关投放节奏：01 双炮；03 散射；04 护盾；06 速射；07 减速；08 双炮/护盾；10 散射；11 速射；13 护盾；14 减速；15 双炮/速射；17 散射；18 护盾；19 速射/减速；20 散射/护盾。02、05、09、12、16 无投放。

## 配置格式

`levels.js` 中每关由三个波次组成：

```js
{
  id: 'level-21', name: '示例关卡', chapter: '掌握', player: { lives: 4, fireRate: .43, speed: 12 },
  waves: [{
    label: '示例波次', count: 8, formation: 'grid', health: 3,
    drift: 3.4, driftPattern: 'sway',
    firstDeployAfter: 3.6, deployEvery: 2.5, deployPattern: 'alternate',
    firstProjectileAfter: 2.8, projectileEvery: 2.4, diveSpeed: 8.8,
    powerDrops: [{ afterDefeat: 4, type: 'shield', landing: 'safe' }], score: 900
  }]
}
```

## 新增关卡清单

1. 先确定章节、主压力与三波职责；不要先堆数值。
2. 选择一项已有机制做识别波的重点，其他机制只做轻量复习。
3. 编排 `powerDrops`，确认它们不是过关必要条件，也不与本波压力冲突。
4. 检查首次危险动作、投放间隔、炮火间隔与安全路线是否符合上方边界。
5. 在手机竖屏实测：可读清队形、可看清强化文字、双手横移不被 UI 遮挡。
6. 补充或调整 `levels.test.mjs` 的配置校验，并运行 `npm run build:galaxian && npm test`。
