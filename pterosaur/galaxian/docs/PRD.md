# 《机械翼龙：投放突袭》PRD

## 1. 产品概述

- **类型**：手机竖屏固定射击试玩。
- **核心幻想**：驾驶双炮积木坦克，在底部迎击从上方巡航、投放并俯冲的机械翼龙战车编队。
- **试玩目标**：用最少的操作建立“观察轨迹 → 横向闪避 → 持续射击”的清晰循环，再以数据驱动方式扩展正式关卡。

## 2. 当前可玩版本

### 玩家

- 玩家单位为黄色双炮坦克，位于战场底部，车顶朝向镜头、车头朝屏幕上方。
- 只可左右移动；键盘支持 `A/D`、方向键，手机支持长按左右按钮。
- 坦克持续向上自动射击。发射键保留触控反馈与后续扩展入口。
- 初始为 4 格装甲；每次有效碰撞损失 1 格。四格都失效则失败。

### 敌方单位

1. **合体翼龙战车**：在上方横向巡航；每台固定需要命中 2 次才会击败。
2. **投放战车**：合体分离时出现，以侧面视图向下坠落；若与坦克横向重叠则造成伤害。
3. **俯冲翼龙**：投放后掉头锁定坦克当时位置，向下俯冲；命中则造成伤害。

### 胜负

- 清除当前波所有合体翼龙战车与已投放战车后进入下一波。
- 完成全部波次即试玩完成。
- 4 格装甲归零即失败，可重新开始。

## 3. 单局流程

1. 点击“开始试玩”。
2. 第一波合体翼龙战车在上方出现并横向巡航。
3. 坦克自动开火，玩家左右移动避开对齐的投放战车与翼龙俯冲。
4. 敌方被清除后进入下一波，直至关卡完成或坦克装甲归零。

## 4. 关卡设计原则

### 节奏

- 一关建议 `60–120 秒`。
- 新关卡每次只提升一个难度变量：数量、投放间隔或俯冲速度三选一。
- 首波用于学习投放与闪避，第二波提高密度，第三波提高节奏；不要同时堆叠所有压力。

### 安全与公平

- 任何时刻至少保留约 `1.3` 个坦克宽度的横向闪避窗口。
- 投放战车与翼龙俯冲不能在同一竖线连续压迫玩家；至少错开半个坦克宽度。
- 敌方、投放物和玩家都必须被限制在相机可见区域内。
- 手机触控、桌面键盘都必须完整通关一遍后才能验收关卡。

### 现有配置字段

配置文件：[levels.js](../levels.js)。每个波次包含：

| 字段 | 含义 | 当前约束 |
| --- | --- | --- |
| `count` | 合体翼龙战车数量 | 正整数。 |
| `health` | 合体耐久 | 固定为 `2`。 |
| `drift` | 横向巡航幅度 | 提升时先验证边界和安全窗口。 |
| `deployEvery` | 投放间隔（秒） | 不低于 `1.8` 秒。 |
| `diveSpeed` | 俯冲速度 | 大于 `0` 且不超过 `8`。 |
| `score` | 击败得分 | 不改变难度。 |

现有校验位于 [levels.test.mjs](../levels.test.mjs)。新增关卡必须补充相应配置测试。

## 5. 非目标

当前阶段不做：联网、排行榜、商店、复杂剧情、可自由旋转镜头、真实战争元素、自动弹窗教学。

## 6. 验收标准

- 手机点击开始后立即显示首波合体翼龙战车。
- 左右长按不会触发文字选择，可持续移动坦克。
- 敌人按配置需要两次命中才被击败。
- 装甲固定显示四格，损失后变灰。
- 投放战车为侧面下落，翼龙为掉头俯冲。
- 页面在窄屏下不出现模型、HUD 或按钮互相遮挡。
