# 《积木翼龙：小蜜蜂》关卡迭代约定

试玩关卡的可调参数集中在 `levels.js`，渲染与碰撞逻辑不写关卡特例。新增关卡先复制配置，再调整数值。

## 每波的可调项

- `rows` / `cols`：翼龙数量与编队轮廓。
- `health`：单只翼龙承受的命中次数；前两波保持 1，避免初学者读不懂反馈。
- `drift`：编队横移幅度。
- `diveEvery`：俯冲间隔；低于 1.5 秒前必须先测试手机触控回避空间。
- `score`：用于表现关卡节奏，不影响难度。
- `boss.health` / `boss.shotEvery`：首领战时长和炮火密度。

## 扩展关卡时的约束

1. 先改变一种变量：要么增加队形，要么加快俯冲，不同时叠加。
2. 每一波必须留出至少 1.3 个战车宽度的横向安全窗口。
3. 首领至少保留一次 1 秒以上的无炮火间隔，给玩家识别与反应时间。
4. 一关目标时长控制在 60–120 秒；若超过，拆成更多波次或降低首领血量。
5. 每次新增关卡都在窄屏与键盘各试玩一次，确认左右按钮不会遮挡战场。

## 美术一致性

沿用 `ART_DIRECTION.md`：暖黄为玩家与奖励，低饱和石绿为环境，砖红仅用于危险和敌方炮火。背景不使用高频纹理或霓虹渐变；特效采用短暂的积木色粒子，避免覆盖模型细节。UI 使用米白底、深灰绿文字与圆角薄边，保持模型展厅和游戏属于同一个积木档案世界。
