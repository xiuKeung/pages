# 翼龙战车 · 美术风格规范

## 风格定位

**风格名：温暖积木档案 · 柔和遗迹战术**

以真实积木的明黄、石墨黑和机械灰为主角，放在浅色、安静、有纸张与展柜感的遗迹世界里。它不是写实战争，也不是高饱和卡通；整体应像一套被精心整理、可以亲手操作的积木档案。

关键词：**积木感、温暖、清晰、轻战术、低压力、可观察、可复盘。**

## 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#F7F8F2` | 偏暖的浅灰白，避免纯白刺眼。 |
| 卡片与面板 | `#FFFEF8` | 轻微奶白，用于信息层级。 |
| 积木明黄 | `#F2C531` | 翼龙、战车与关键交互的品牌色。 |
| 石墨黑 | `#323B32` | 履带、连接件、主按钮与重要文字。 |
| 机械灰 | `#748172` | 关节、轮毂、地形和次要结构。 |
| 遗迹绿灰 | `#EDF1E7` | 棋盘格、常规地面、弱强调背景。 |
| 能源金 | `#F3C73B` | 电池、补给、可收集物和正向反馈。 |
| 预警珊瑚 | `#E99B80` | 敌方下一步攻击范围与风险提示。 |
| 成功青绿 | `#A9C9A0` | 已通电、已完成、修复与安全区域。 |

规则：预警珊瑚只用于**将发生的危险**；不要把敌人、按钮、背景都染成红色。黄色在一个画面中只承担一个核心注意点：可互动目标、当前单位或主行动按钮。

## 3D 模型与材质

- 保留积木的分件、圆角、卡扣、球形关节和轻微塑料高光；不要把它们渲染成金属机甲。
- 主模型使用真实的明黄 / 石墨黑 / 机械灰比例；新增模型也先从这组三色中取主色和结构色。
- 环境材质采用磨砂石板、低细节岩块、半透明能量玻璃和柔和植被色块。表面纹理少而清晰，不加噪点脏污。
- 光照为柔和顶光加轻微暖侧光，阴影边缘柔软。背景雾使用浅绿灰或浅蓝灰，不能压过模型轮廓。
- 3D 棋盘单元有清楚的边界与轻微高度差；可走、不可走、危险和目标格一眼区分。

## 战术场景

### 棋盘

- 使用小型格状遗迹：建议 `6 × 8` 至 `8 × 8`，单关画面完整可见。
- 地面为遗迹绿灰；岩块、断墙和高台用机械灰及低饱和苔绿。
- 预告攻击范围采用半透明珊瑚色平面或细描边，不遮挡格子与单位。
- 目标物使用能源金，并配合简洁的光环、向上浮动或脉冲，不使用持续强闪。

### 两个主单位

| 单位 | 视觉职责 | 行为表现 |
| --- | --- | --- |
| 机械翼龙 | 空中、轻盈、观察 | 起飞时轻微抬升，移动时侧倾；标记目标时出现细金色环。 |
| 双炮战车 | 地面、稳定、推进 | 履带缓慢位移，炮塔先旋转再射击；行动结束有轻微停靠回弹。 |
| 对接状态 | 协作、补给、组合技 | 两个单位靠近后出现黄色接口线与低频光晕，不做夸张爆炸。 |

镜头以斜侧俯视为主，单位轮廓始终清楚。单关开始、组合技和通关可短暂推近；玩家操作和敌方预告期间保持稳定，不持续晃动镜头。

## UI 与排版

- 网页与游戏共用档案式界面：浅底、细边框、圆角卡片、墨绿色文字、少量黄色重点。
- 信息结构按“作品 / 目标 / 行动 / 结果”排列。游戏 HUD 只显示当前回合、核心稳定度、行动提示和目标。
- 字体采用系统无衬线；标题紧凑、有重量，正文保持较短行距。避免科幻军用字体与长段全大写英文。
- 图标使用圆角线性 SVG，描边颜色为石墨黑或机械灰；图标与文字垂直居中。
- 手机端优先：棋盘占视觉中心，常用操作在底部或右侧浮层；复杂说明收进“玩法说明”抽屉。

## 动效与声音

- 动效服务于状态：可行动、已标记、受威胁、已对接、成功完成必须分别可辨。
- 标记、炮击、对接的单次动画建议在 `180–700ms`；不做长时间等待演出。
- 受击可使用一次短促边缘闪光和极轻震动；系统减少动态效果时取消镜头震动并减少粒子。
- 声音方向为轻塑料卡扣、低频机械伺服、柔和提示音；避免真实枪炮、战争警报和持续噪声。

## 禁止项

- 不使用写实废墟、血迹、火焰、重军事 HUD 或阴暗末日滤镜。
- 不使用霓虹紫 / 荧光绿 / 高饱和红蓝作为大面积背景。
- 不让场景装饰、漂浮方块或粒子遮挡棋盘与模型。
- 不把危险仅靠颜色表达；同时提供格纹、描边、图标或文字提示。
- 不为“酷炫”增加与玩法无关的持续镜头旋转、镜头抖动或自动弹窗。

## 新内容验收清单

新增模型、关卡或界面前检查：

1. 是否在明黄 / 石墨黑 / 机械灰的结构体系中有清晰归属？
2. 是否能在浅色遗迹背景中一眼看出主单位、目标和下一步风险？
3. 是否让翼龙和战车拥有不同且互相需要的视觉与玩法职责？
4. 是否在手机竖屏下保留足够大的棋盘和触控目标？
5. 是否减少了装饰性元素，让玩家先看见行动信息？
