# 机械翼龙战车 · 积木档案

独立静态 3D 展示页。所有运行依赖、十八张参考照片和 GLB 模型均保存在本目录，无需 CDN、账号或构建步骤。

## 本地浏览

在此目录执行 `python3 -m http.server 8080`，然后打开 `http://localhost:8080/`。也可以从 Pages 目录启动服务器，访问 `/pterosaur/`。ES 模块需要 HTTP 服务，不支持直接双击 `index.html` 后以 `file://` 运行。

## 内容与交互

- 根据用户提供的十八张照片，使用几何积木重建黄色四轮底盘与车顶机械翼龙。
- 鼠标／触摸旋转、滚轮／双指缩放，透视、侧面、正面及俯视切换。
- 完整组合、分离同屏、翼龙独立、战车独立四种展示模式。
- 翼龙站立／伏卧切换，翼部关节、头部俯仰、分层展示、自动旋转、线框、重置、全屏。
- 十八张照片按组合／翼龙／战车筛选；新增照片使用以模型为中心的轻量缩略图，大图保留原始分辨率。灯箱在当前分类内翻页，方向键翻页、Esc 关闭。
- 下载链接随展示模式与站立／伏卧姿态切换；导出基础姿态，不含滑杆临时调整。
- 六份 GLB：`mechanical-pterosaur.glb`（组合）、`pterosaur-standing.glb`（站立翼龙）、`pterosaur-resting.glb`（伏卧翼龙）、`carrier.glb`（战车）、`detached-pair.glb`（站立分离）、`detached-resting.glb`（伏卧分离）。

这是以照片为依据的几何近似重建，不是摄影测量扫描或自动生成的高精度网格。照片中未显示的底面和遮挡部分按可见结构补全。展翼和分层是用于查看结构的演示动作，不代表实体玩具已验证的运动范围。模型坐标采用任意单位，不代表实际尺寸。下载文件仅含模型，不含网页展示台或背景。

## 第二版校正

- 根据脱离照片，将大梯形斜板归属修正为固定车顶板，不随翼龙移动。
- 增加车顶四凸点接口、双灰色格栅、车头中央曲面、尾部圆形红灯与空心杆帽。
- 重建翼龙双片曲面长喙、单颈球节、双腰接头、膝部轴铰、踝部球节、空心脚底，以及小翼背面的连接孔。
- 头、腰、膝、脚分层连接，同一套几何体切换伏卧／站立；独立形态根据几何包围盒接地。
- 合并每个轮胎的静态胎纹，新增细节后整套模型仍只需 226 个网格（第一版 588 个）。

## 修改与导出

`model.js` 定义模型，`main.js` 控制展示和交互，`style.css` 定义响应式样式。

修改模型后执行 `node export-model.mjs` 更新 GLB。Three.js 0.170.0 及其 OrbitControls、GLTFExporter 已放在 `vendor/`；MIT 许可证见 `vendor/THREE-LICENSE.txt`。两个扩展仅将导入路径改为本地路径。

此目录是独立网页，没有修改其他业务页面，也没有执行部署。

## 变身动画（第三版）

点击“播放变身动画”进入 20 秒演示：战车驶入（0–3s）、接口抬升（3–4.5s）、侧向脱离（4.5–6s）、展开站立（6–8.5s）、展翼（8.5–10.5s）、镜头环绕（10.5–14s）、收拢合体（14–20s）。空中抬升及移位是展示编排，不表示玩具具备自主悬浮功能。

- 播放／暂停、重播、倒放、逐帧拖动时间轴，以及 0.5／1／1.5／2 倍速。
- 所有姿态由绝对时间计算，拖动与倒放不会积累位置误差；先移离车顶再站立，先收拢再归位。
- 动画运行时暂时锁定手动姿态与视角；退出或点击重置恢复组合形态。全屏模式包含播放器。
- 网页隐藏或展厅离开屏幕时自动暂停；不会自动恢复播放。系统减少动态效果设置会关闭动画中的环绕镜头。
- GLB 下载仍是静态基础模型，不包含这段网页动画。

`animation.js` 定义编排与播放器；在本目录运行 `npm test`（或 `node --test animation.test.mjs`）检查分离顺序、正反放一致性、结束／重播／速度边界以及站立接地。
