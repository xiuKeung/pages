# 安家笔记图标风格规范

确定日期：2026-10-28。基准为已有 App 图标，不以第一版扁平 SVG 入口图标为基准。

## 风格基准与适用范围

- 唯一主参照：[app-icon-coral.png](app-icon-coral.png)。新增图标必须同时提供这张图片作为风格参考，不能只靠文字描述。
- 风格名称：**暖色软质黏土立体图标**。
- 适用于 App 品牌图标、首页功能入口及未来新增功能图标。普通文字旁的小操作符号不必做成立体图标。
- 本规范从现有图标视觉中提炼；下列色值是后续设计的目标参考，不是原图每个像素的精确采样。

## 固定视觉规则

| 维度 | 规则 |
| --- | --- |
| 材质 | 哑光软黏土，轻微细腻纹理；避免塑料亮面、玻璃、金属、扁平描边 |
| 造型 | 圆润厚实，有真实体积、倒角和层叠关系；不使用尖锐细线 |
| 主色 | 珊瑚红 `#F5654D`，用于房屋、主体或醒目的功能标记 |
| 辅色 | 奶油黄 `#FFE17A`，用于纸页、显示屏或位置标记 |
| 深色 | 炭灰 `#343F42`，用于笔、按键、装订环等识别部件 |
| 底色 | 暖白 `#FFFCF1` 圆角方块；各功能不分别换成蓝、绿、紫底 |
| 光照 | 统一左上柔光，右下与接触处暖色柔影；不过曝、不加霓虹光 |
| 视角 | 近正面，少量厚度可见，不做明显等距斜视 |
| 构图 | 单一主体或紧密组合，视觉居中；主体约占画布 76%～82%，保留安全边距 |
| 底板 | 正方形、圆角约边长 22%～24%；透明外角；页面统一圆角裁切避免生成边缘毛刺 |
| 细节 | 至多一个主符号和一个辅助符号；不写文字、数字、品牌、水印 |

## 后续新增流程

1. 明确一个功能主符号，避免和现有四个图标混淆。
2. 使用原 App 图标作为参考图，复用共享提示词，只调整 Subject 部分。
3. 单独生成图标，保留高分辨率原图和透明通道；新版本用新目录或后缀，避免覆盖已确认素材。
4. 并排检查材质、光向、暖色配比、主体比例与视觉居中。
5. 必须在 54px、62px 及浅色/深色底上检查辨识度、圆角边缘和阴影，不能只看大图。
6. 确认采用后再生成适合网页加载的缩小 PNG/WebP，保留原图；资源放在工程内，不引用生成缓存路径。
7. 接入页面时统一尺寸与裁切规则，不为单个图标堆叠临时位移修正；同步 App 资源，并按需要打包。
