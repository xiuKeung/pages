# 安家笔记

安家笔记是一套以静态网页为业务源码、同时可构建为 iOS / Android App 的本地购房工具。所有数据默认保存在当前设备，不依赖账号或服务端。

本文对应 2026-10-28 的网页 **v2026.10.28.10**、App **1.1.23**。网页版本位于 `entrance/index.html`；Android 和 iOS 版本分别在 `app/android/app/build.gradle`、`app/ios/App/App.xcodeproj/project.pbxproj` 中维护。

## 工具

| 页面 | 用途 |
| --- | --- |
| `entrance/` | 工具首页与浅色 / 深色 / 系统主题设置 |
| `viewings/` | 看房记录、学校匹配、月供估算、房源图片与 ZIP 备份 |
| `comparison/` | 多套房源对比、差异筛选、横屏查看及朝向图预览，从看房记录进入 |
| `school/` | 南山、福田官方学区信息查询与数据更新 |
| `calculator/` | 商贷、公积金、组合贷的等额本息 / 等额本金对比 |
| `checklist/` | 购房流程清单与本地进度、备注 |
| `weight/` | 体重记录、增长趋势与阶段统计 |

首页的四个入口依次为看房记录、学区查询、房贷计算器、购房清单；房源对比由看房记录发起。

## 当前看房记录功能

### 记录与快速录入

- 新增、查看、自动保存、复制和删除记录，支持搜索联想、关注等级复选筛选、数量统计和分批加载。
- 卡片操作顺序：查看、再记一套、查学区、算月供、复制信息、删除；更多信息与房源图片可折叠。
- 详情在独立覆盖层中编辑；返回或收起详情后恢复列表位置，小区名为空的新记录可取消。
- 小区名称支持联想、复制和地图跳转；小学、中学自动匹配且允许手动修改、清空、复制和地图跳转。两项均已有内容时，修改小区名不再次自动覆盖学校。
- 现场快速记录顶部小学、中学各占一行；其余常用字段按左右两列排列：楼栋 / 单元、总楼层、面积、户型、建成年份、梯户比、报价、阳台朝向。
- 建成年份可选至当前年份加 10 年；梯户比可选择预设或手动填写。
- “更多房源与贷款信息”默认展开，包含看房日期、关注等级、物业、车位及贷款参数；另可填写房源链接、优缺点、附近地标和备注。
- “再记一套”带入小区、物业、建成年份、车位及学校公共信息，新建独立记录；不复制房号、报价、图片和个人评价。

### 贷款默认值、朝向与快捷标签

- 标题右侧“设置”可保存贷款年限、首付比例、商贷年利率默认值，初始为 30 年、30%、3.05%；仅影响后续新增及“再记一套”，已有记录和独立计算器不变。
- 贷款期限支持 1～40 年；根据报价与贷款参数自动计算首付、贷款金额、等额本息和等额本金月供。
- 阳台朝向支持直接输入或手动罗盘。顶部指示线固定，拖动 / 点击外圈选择方向；不调用手机指南针、传感器或定位，也没有自动实测。
- 朝向以“正南”“南偏西30°”等文字保存，45°边界以南/北为主。详情根据记录绘制实际朝向缩略图，点击可调整；对比页缩略图可点击放大。
- 优点标签：采光好、安静、通风好、户型方正、视野开阔、交通方便、高赠送、高得房率、大阳台、南北通透、明厨明卫、人车分流、绿化好。
- 缺点标签：临街噪音、采光遮挡、装修旧、有渗水、户型不规则、停车困难、西晒、暗卫、对视严重、电梯等待久、人车混行、物业维护差。
- 标签点击追加且不重复添加，优缺点文字仍可自由编辑。

### 图片与房源对比

- 支持多选图片、拍照、添加进度提示、缩略图、单张及总大小展示。
- 大图支持缩放、滑动 / 按钮切换，保存当前图片或本记录全部图片；App 可保存到系统相册。单图和整条记录删除均需确认。
- 至少选择两套房源才能打开对比，不限于四套；对比基本信息、房屋信息、物业车位、地标、学校与贷款、优缺点及备注等。
- 对比可只显示差异项，使用一张共用表整体横向滚动，项目标题固定；提供手动横屏按钮，受浏览器旋转能力限制时提示手动横置设备。

### 导入导出

通过“备份”二级菜单进入导入或导出：

| 操作 | 范围和行为 |
| --- | --- |
| 全量导出 | 全部看房记录及其图片，生成 ZIP |
| 选择记录导出 | 仅所选记录及图片；选择列表显示小区、房号、关注等级和看房日期 |
| 增量导入 | 保留已有记录，将备份内容作为新记录追加，重新分配关联 ID；不按旧 ID 或更新时间去重 |
| 覆盖导入 | 替换本机全部看房记录及图片；勾选确认后才可执行 |

导入有进度提示。看房记录备份不包含购房清单、贷款方案、学区收藏、官方学区数据或贷款默认值设置。重复增量导入会产生多份记录。

完整操作行为、字段清单及源码位置见 [App README 的看房记录功能](app/README.md#看房记录功能)。

## 目录结构

图标设计统一参考 [安家笔记图标风格规范](app/assets/ICON_STYLE.md)，生成提示词见 [ICON_PROMPTS.md](app/assets/ICON_PROMPTS.md)。首页已使用这套黏土风格入口图标，网页与 App 共用资源；可在 [预览页](entrance/icon-preview.html) 并排查看。

```text
Pages/
├── entrance/      工具首页
├── viewings/      看房记录
├── comparison/    房源对比
├── school/        学区查询及官方数据同步脚本
├── calculator/    房贷计算器
├── checklist/     购房清单
├── weight/        体重记录与统计图表
├── shared/        由 App 构建生成的网页共享运行时
└── app/           Capacitor 原生壳、iOS / Android 工程和构建脚本
```

网页目录是唯一业务源码。不要直接修改 `app/www/`、`app/android/app/src/main/assets/public/` 或 `app/ios/App/App/public/`；它们由构建脚本生成。

## 日常开发流程

1. 修改对应网页目录，在浏览器中验证；
2. 需要发布网页时，提交并推送网页源码；
3. 需要更新 App 资源时，在 `app/` 执行 `./build-app.sh sync`；
4. 需要 Android 调试安装包时，在 `app/` 执行 `./generate-apk.sh`。

学区官方数据的维护流程见 [school/README.md](school/README.md)。App 构建、原生存储和备份流程见 [app/README.md](app/README.md)。看房记录的数据字段与图片机制见 [viewings/README.md](viewings/README.md)。

## 本地数据与备份

- 浏览器版看房记录文字保存在 localStorage，图片保存在 IndexedDB；
- 原生 App 将看房记录存入 SQLite，房源图片存入 App 私有目录，数据库保存图片元数据和路径；
- 新增房源的贷款默认值作为设备偏好保存在 localStorage（App 中为 WebView 的 localStorage）；
- 看房记录可导出包含图片的 ZIP 备份，也可导入恢复；
- 删除记录会清理其文字及关联图片；手动罗盘按朝向文字生成 SVG，不额外存储罗盘图片；
- 没有账号、服务端或跨设备自动同步，分享和迁移依靠手动备份；
- 卸载 App 或清除浏览器站点数据会删除该设备本地数据，请定期导出备份。
